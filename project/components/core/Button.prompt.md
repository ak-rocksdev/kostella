Kostella action button — plum primary for the single main action (e.g. "Jadwalkan survei"), secondary bordered for the alternative ("Ajukan sewa"), ghost for tertiary, inverse for use on dark `--ink` blocks.

```jsx
<Button variant="primary" size="lg">Jadwalkan survei</Button>
<Button variant="secondary" size="lg">Ajukan sewa</Button>
```

Variants: primary | secondary | ghost | inverse. Sizes sm/md/lg. Radius 4px, sentence case labels, no icons inside buttons.
