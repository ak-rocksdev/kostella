# UI kits — Kostella pitch screens

Four concept screens (desktop 1440), all composed from `components/core/` via the compiled bundle. Real data from the brief; no lorem ipsum. Photos are placeholders — the brief forbids stock photos; real Kostella photos to be dropped in.

- `beranda/` — homepage: hero + live availability card, chip search, proof bar, kawasan cards, cost receipt, cara sewa, dark franchise block, trust footer.
- `pencarian/` — search results: 60/40 list + sticky neighborhood map (concept), chip filters, designed empty state.
- `detail/` — property 362: giant number head, signature floor grid (click a room → sticky panel updates), full receipt incl. hidden-fee rules, walking-radius map, house rules.
- `dashboard/` — operator view: property picker, 4 metric cards, same floor grid with actions, bills table, today's surveys.

Maps are labeled "peta konsep" — replace with real map tiles in production.
